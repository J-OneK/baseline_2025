召回与排序各自学什么？

召回内积 sretrieval(u,i) = quTvi

最终分 sfinal = DCN V2(15 项特征) + 联合残差

召回训练让每个真实点击在 64 个采样负例中得分更高。排序训练使用实际合并的 500 条候选，按留出点击所在列做列表交叉熵。DCN V2 直接用汇总特征打分，联合模型读取逐次曝光与点击并学习额外的分数修正。两个旧分仍是输入，固定的 0.9 / 0.1 融合只保留作候选保护与对照。

自测：为什么推荐时必须加载同一份checkpoint与广告索引？

索引中的广告向量由某一份模型参数生成。换了序列模型或广告编码器参数后，新的用户向量和旧广告向量可能不在相同的打分空间中。当前代码用checkpoint摘要等元信息检查对应关系；重新训练得到新权重时，应重新导出向量并建立相应索引。
