## 决策和边界

- 同时对比原模型与正常微调对照，避免把额外训练的收益误认为门控收益。
- 全体Recall@500至少保留99%，NDCG@10至少保留95%，冷启动与长尾均不下降，冷尾宏平均严格改善。
- Pilot锁定scale和epoch后才训练另外两个种子；未通过复核就停止，不再搜索新参数。
- 初始三组无合格改善但存在长尾增益时，仅允许一次预定scale0.75；其他结构保持不变。
- 新确认集是否评估：False。不把开发结果表述为新确认收益。
- 新确认队列排除已知评估过的31574个RID；用户训练前缀仍参加训练，不是训练未见新用户实验。
- 仍是公共静态目录、逐用户时间截断，不是统一时间生产回放。
- 本研究没有自动替换原主分支、checkpoint或Faiss索引；仅在实际通过后讨论最小集成。
